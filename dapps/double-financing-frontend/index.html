Quick Demo Guide

1. Connect: Click "Use Test Wallet" to connect with the pre-funded test account.

2. Register: Enter asset ID 999 and click Register Asset.

3. Finance: Enter asset ID 999, amount 1, click Pledge Asset.

4. Try Fraud: Try to pledge asset 999 again - it will FAIL and flag your account!

5. Repay: Repay the loan (1 ETH) to release the lien.

6. Check Fraud: Click "Refresh Flagged Accounts" to see flagged addresses.

7. Events: Click "Start Listening" to see real-time blockchain events.

8. Upload File: In "Off-Chain File Storage", enter asset ID, upload a PDF, click "Compute Hash", paste an IPFS URI, click "Register File".

9. Verify: Use "Verify File Integrity" to confirm a hash matches the on-chain record.
